装调台上要把薄透镜、空气间隔和球面折射面串成一条近轴光路。给定入射高度与近轴角，需要立刻得到出射光线、整段系统矩阵，以及某个物距对应的像距和横向放大率。把光路登记成具名档，点名一档就能追迹；也可以把元件清单写在当次请求里只用一次。这是近轴几何光学后端，不接镜头电商、不写滤镜相机，也没有账户。

光线用列向量表示：第一分量是高度 y，第二分量是近轴角 u。约定全程用这套角，不要中途改成光学方向余弦又换回来。空气中的自由空间传播距离 L，对应矩阵第一行是 1 与 L、第二行是 0 与 1。薄透镜焦距 f，对应矩阵第一行是 1 与 0、第二行是负 1 除以 f 与 1；f 不得为零。球面折射要带曲率半径 R 以及面两侧折射率 n1、n2，折射率必须为正。未知元件种类、把负的间隔说成正向传播、焦距为零，都在追迹前退回并说明哪一项不合规。空气间隔接到空气间隔、中间只夹薄透镜时，每一段矩阵以及整段乘积的行列式都必须是 1，只允许钉死的浮点容差。

系统矩阵按光线前进方向把各元件矩阵依次乘起来。物在第一面左侧、物距 s 取正。像距由共轭条件解出：出射高度与物点对应，等价于整段矩阵的 B 分量配合物距使像方满足成像；单个薄透镜必须能从这套矩阵还原出高斯公式，物距、像距、焦距三者满足倒数和等于焦距的倒数。平行光入射（物在无穷远）时，像落在后焦面，有效焦距取空气中负 1 除以整段矩阵的 C 分量。两块薄透镜间距恰好等于两焦距之和时，系统接近无焦，C 分量逼近 0，横向放大率逼近负的后焦距比前焦距；把间距拉开或缩短，焦度必须重新出现，不能仍报无焦。

球面折射从 n1 进入 n2 时，近轴角按折射定律接到新介质，曲率半径的符号与光路前进方向一致：凸向入射一侧取正。两侧折射率相等时，这块面必须退化成什么也不做，出射角等于入射角。从空气进玻璃再出到空气，整段行列式仍须回到 1，不能因为中间折射率大于 1 就把行列式写成 n 的某个次方还声称自洽。

必须守住的往返关系：任意合法光路，把光线正向追一遍，再按相反次序用各段矩阵的逆作用回去，入射的 y 与 u 要在容差内还原。只改某一块透镜的焦距，有效焦距与放大率都要跟着变，不能只改打印值。服务须内置一条共焦望远镜示范档：两透镜、间距等于焦距之和，放大率为负，C 分量接近 0。

具名光路档要能登记、列出、按名追迹。列出时给出元件种类与参数全文，追迹结果给出系统 A、B、C、D、有效焦距、给定物距的像距与放大率、出射 y 与 u。未登记的档名拒绝，不猜测。缺项、非有限数、折射率非正，返回带类型的错误。同时追迹两档时，矩阵与光线不得串到对方。

实现用 Python 3.12 与 FastAPI。光路档写入进程内 SQLite。镜像基于 python:3.12-slim，一条 docker build 再 docker run 即可对外提供 HTTP。按职责拆到多个文件：元件矩阵、系统连乘与物像求解、档的存取、入参检查各成模块，不要堆进同一个文件。测试须钉死：空气系统行列式为 1、单透镜还原高斯公式、共焦望远镜 C 接近 0 且放大率为负、正向再逆向还原入射光线、焦距为零被拒、未知元件被拒、未知档名被拒、同时追迹两档结果不串号。
